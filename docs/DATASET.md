# Dataset

## Source and access

The paper's data was provided by **AbsoluIT** (https://absoluit.com), a Norwegian company
operating a taxi fleet-management system, and covers roughly one year of vehicle-tracking
logs from Norway (per the paper). Per the notebook, the file is called `TripLog.csv`.

**The dataset is not included in this repository.** I was not given its licence or
redistribution terms, so it is treated as proprietary. Researchers who want it should
contact the paper's authors and AbsoluIT; this repository cannot grant access.

For development and demonstration the repository ships a **synthetic** file,
`data/sample/TripLog_sample.csv`, with the same schema, generated by
`python -m magnetic_points make-sample`. It is not a statistical model of the real data.

## Raw schema (`TripLog.csv`)

| Column | Type | Meaning |
|---|---|---|
| `TourId` | integer | identifier of a tour/trip (the paper's text calls it `VehId` in places). Dropped in preprocessing. |
| `VehLat` | float | latitude of the vehicle at the time of the log (decimal degrees) |
| `VehLng` | float | longitude of the vehicle at the time of the log (decimal degrees) |
| `Status` | integer | `6` = pickup, `8` = drop-off (the only codes the paper mentions) |
| `CreatedDate` | datetime | `YYYY-MM-DD HH:MM`; the notebook output shows dates starting 2024-01-01 |

Row counts from the notebook output: **242,509** rows, 121,422 after keeping pickups.

## After preprocessing (`TripLog_DataSet.csv`)

| Column | Meaning |
|---|---|
| `VehLat`, `VehLng` | pickup position |
| `Hour` | 0–23 |
| `Minutes` | 0–59 |
| `DayOfWeek` | 0 = Monday … 6 = Sunday |

## After clustering (`TripLog_Clustered.csv`)

Adds `Cluster` (spatial cluster id) and `SubCluster` (= `DayOfWeek`).

## Privacy note

The logs are vehicle positions, not passenger records, but they are still location data.
Do not commit raw or processed real data; `data/raw/` and `data/processed/` are git-ignored.
