# Code of Conduct

We want this project to be a welcoming, harassment-free space for everyone, regardless
of experience, background, identity, or nationality. This code is adapted in spirit from
the Contributor Covenant (https://www.contributor-covenant.org).

**Expected behaviour:** be respectful and constructive; give and accept feedback
graciously; focus on what is best for the community and the research; credit others' work.

**Unacceptable behaviour:** harassment, discrimination, personal attacks, trolling,
publishing others' private information (including real location data or credentials),
and other conduct that would be inappropriate in a professional setting.

**Enforcement:** maintainers may remove, edit or reject contributions and may ban
contributors for behaviour they judge inappropriate. Report concerns to the maintainers
via a private GitHub security/advisory contact or the contact listed on the maintainers'
